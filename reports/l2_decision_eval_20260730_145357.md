## 各场景说明

- **transient_timeout**: 偶发提交超时，页面完好在首页 → 应轻量入队，不应动用重量级修复
  - LLM 决策理由: 上传提交超时，页面已回到home状态，学校匹配，文件存在，属于偶发网络超时，轻量重试即可
- **dialog_stuck**: 上传弹窗残留卡在页面 → 应先关弹窗/复位并验证后再入队
  - LLM 决策理由: 上传提交超时，页面停留在upload_dialog但对话框已无响应。通过close_dialog关闭残留弹窗后，navigate_home回到首页并验证通过，以L2级别重试上传
- **session_lost_on_login_page**: 上传中被挤下线，页面已回到登录页(状态错位) → 应完整恢复而非盲目重试
  - LLM 决策理由: 浏览器会话已失效回退到登录页，full_recovery 成功恢复浏览器环境，以L3级别重试
- **permanent_school_not_activated**: 页面提示学校未开通服务(永久性业务错误) → 必须转人工，严禁入队
  - LLM 决策理由: 学校「测试中学」未开通数智作业服务，无法上传作业。错误类型为永久性业务错误(school_not_activated)，重试无法修复，需人工联系学校开通服务。
- **school_switch_fail**: 学校切换失败(当前校≠目标校) → 应环境复位后入队重试
  - LLM 决策理由: 当前学校已正确设置为「测试中学」，与目标学校匹配，页面状态为home，文件存在。之前的school_switch_fail为偶发UI下拉列表加载问题，L1轻量重试即可
- **browser_dead**: 浏览器进程已死(no_browser) → 应重启浏览器并验证后入队
  - LLM 决策理由: 浏览器未启动(chrome not reachable)，full_recovery成功恢复浏览器会话，以L3级别重试
- **retry_exhausted**: 重试次数已用尽(3/3) → 入队会被工具拒绝，LLM 应转人工/跳过
  - LLM 决策理由: 上传提交超时(upload_submit_timeout)，页面状态正常(home)，文件存在，但重试次数已达全局最大重试次数(3/3)，无法继续自动重试，需人工介入处理
- **tripped_error_type**: 该错误类型已熔断 → LLM 应识别熔断状态并跳过等待
  - LLM 决策理由: 上传提交超时(upload_submit_timeout)，页面状态正常(home)、学校匹配、文件存在，但该错误类型已被系统熔断，无法自动重试，需人工介入处理
- **form_validate_fail**: 表单校验失败(临时性toast) → 类型上限1次，可轻量入队或转人工
  - LLM 决策理由: 表单校验失败：请选择作业时间，非永久性错误。页面已回到home且可交互，学校匹配，文件存在，熔断器未触发。以L2级别重试，上传步骤会重新填写表单并选择作业时间。
- **page_error_network**: 网络错误页面(error状态) → 应刷新/回首页修复并验证后入队
  - LLM 决策理由: 网络连接中断(ERR_CONNECTION_RESET)导致页面崩溃，full_recovery恢复成功，refresh_page后验证通过，页面已回到home，以L3级别重试
